# Angular + Tailwind Dashboard Prototype

This folder contains **Angular (TypeScript) + Tailwind CSS** dashboard components for the Profile Management UI.
- Designed with gradient headers, pastel cards, soft shadows, 18px radii, and Inter/Segoe UI font.
- Modern, reusable component patterns for Statistic Cards, Tabs, Search/Action Bar, Data Table with pill badges and icon actions.

**Components:**
- `gradient-header.component.ts/html/css`: Reusable top gradient header.
- `info-card.component.ts/html/css`: Statistic/info-card with colored accent and badge support.
- `tabs.component.ts/html/css`: Flexible filter tab strip.
- `search-bar-cta.component.ts/html/css`: Search box and '+Create Profile' action.
- `profile-table.component.ts/html/css`: Data table with badges and icon actions.

_This is an Angular source code drop-in, meant for reference and migration into the actual Angular CLI project structure. The provided CSS uses Tailwind utility classes. You will need to wire Tailwind, the specified fonts, and Angular Material Icon pack as noted in your environment._
